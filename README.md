# Personal Kitty Terminal Configuration

My personal kitty terminal configuration, using the Gruvbox Material Dark Hard theme with some other configuration changes, including box cursor, no terminal bell, slightly larger default font size and diagonal tab format.

### Instructions

1. Install kitty terminal on your Linux machine.

2. For the vast majority of Linux distributions, you can input the following command and get the whole configuration ready to use:

` git clone  https://github.com/yeghia-s/kitty-config.git ~/.config/kitty/`
